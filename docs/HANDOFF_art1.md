## Tools (art/)
- `art/rprobe.js <url> <code-file> [fra|ath]`: enters roam (normal gfx), evals each part of the file in module scope (`__g9ev`). Parts are separated by `\n//---\n`; `//WAIT ms` and `//SHOT path` are directives; a result starting with `td ` saves `window.__td` (a PNG dataURL) to `$TD`.
- Top-down "downward ray": an orthographic render from 800 m up, sampling pixels (`RS_strip` in 98rs). Road/ground meshes free their CPU arrays, so CPU raycasts can't see them.
  **Only valid near the car**: far tiles draw the low-detail map (roads vanish, zebras stay), so a whole-city scan gives false gaps. Warp first, wait about 15 s.
- Running 2 headless pages in parallel makes timers slow (GO results come back `undefined`); run them one at a time.

- The ground has no slope colouring: worldGroundBuild (60_city_build.js:98) only colours by biome/hash, and the inner ground (60:497) uses walk/grass materials.
