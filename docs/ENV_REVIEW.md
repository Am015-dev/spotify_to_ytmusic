# ENV review: ground, mountains, water, foliage, sky (lane env-rev, 2026-10-16, built page out/v90m-beta.66)
Docs only. This is the spec for lane env-1. Alex: "no variation to environment: same green fields, same ugly mountains, same water, no colour variation, no realism, very repetitive." **He is right; the cause is in the code, not taste.**

Shots (852×393, `tools/tEnvRev.js`, png converted to jpg, swiftshader, built page over http): `docs/shots/envrev/grid.jpg` (raw: `raw/`, `raw2/`).
Looked at, honest caveats: (2) Taunus: only the first streamed tile shows, a thin green ribbon in a pale void (lazy zone not built after 16 s headless); (7) Lycabettus spot is a lime lawn with LEGO trees and town, not the hill; (8) Athens drive is the loading screen (headless stream is slow). **Athens has no sea/coast at all** (no water mesh outside the Main in Frankfurt; `WATERS` is empty for Athens), so no coast shot exists; that is itself a finding.

## 2. Audit (grep, exact places)
**Ground materials and colours**
- Outer land (everything outside the city, most of what you see from the road): ONE material `tm` = `groundTex('grass')` 256² (flat #5aa83a + 3000 dabs, `src/53_terrain_roads.js:469`) × vertex colour, UV period 14 m (`src/60_city_build.js:103-106`). Mesh cells are **200 m** (`cs:200`, 25 m only beside water), so vertex colour cannot show anything finer than 200 m.
- Vertex colour = `hsh(round(x/250), round(z/250))`: a hash per **250 m cell**, brightness ×(0.9..1.1) of base `WGC` (#7aa860 fra / #a9a77a ath), blocky cells, **same hue**. Frankfurt extras: `field` = 5 near-identical greens `FC` (#9cb85a #7aa860 #b8b860 #8aa04a #a0a868, picked per 250 m cell), `forest` = #5a8a48 lerp base, `air` = base+#b8b860. Athens: `villa` lerp #5a8a48, `quarry` #d8c6a2, hill >1.5 m lerp #7f9a5a. That is the whole colour system: **≈ 8 colours, 0 noise, 0 slope, 0 height bands, 0 sand/dirt/snow** (grep: no "snow" in `src/5*`/`src/60*`, no "sand").
- City ground: `M.grass` (`gm('grass',0x7aa860)` / `athGrassTex()`), `M.walk`, `M.rock`, `M.cobble`, `M.yard`, `M.dirt`, road/junction (`src/60_city_build4.js:13`), all flat colours, **no vertex colour** (`gndBuild` call at `:18` passes no `col`). 6-7 ground materials per view (matches `docs/CITY_VARIETY.md`).
- Biome/zone system exists but only drives props and 1-line colour switches: `BIOMES` (`src/60_city_build.js:98-101`, Frankfurt 8 rects: fraport/taunus/homburg/wetterau/offenbach/hoechst/osthafen/stadtwald; Athens from `RF.biomes`), `ZONES` (`src/53_terrain_roads.js:264`). Palette per biome = the lines above, so Wetterau "fields" are 5 greens at 250 m.
- `98lf_lively_fill.js` (LF) adds flower beds / tufts / mounds, but only in **open city cells** (`LF_ctx` uses street samples, `:70-77`); nothing in the outer land. Flower palette `LF_FC` exists (#d8302a #ffd12c #ffffff #f28ac0 #3f7fe0 #ff8a1c).

**Mountains (why they look the way they do)**
- Frankfurt Taunus: `tauRaw` (`src/53_terrain_roads.js:257-262`): `h = 70·smoothstep(v/3400) + (16·sin(u/340+1.3)·sin(v/380) + 4·sin(u/150)·cos(v/170))·ramp`. = a 70 m linear-ish ramp with ~2 km-wavelength ±16 m swells. No ridged noise, no erosion, no cliffs. Mesh `taunusBuildG` (`src/60_city_build.js:72-76`): 20×25 m grid, `computeVertexNormals`, material `HUB.tauMat` **`flatShading:true`** (`src/60_city_build4.js:6`) => faceted look. Colour = `lo #d6f0a8 → mid #a8d888 → hi #e8e2cc` by `h/75` only, lerped to base at the edge. Trees: 2600 pines/trees in `TC` 4 greens.
- Sachsenhäuser Berg: `hillH` = `32·(1-q)²` paraboloid (`:210, :265`); same ground colour as the field (shot 4).
- Athens hills (Lycabettus, Filopappou, Akropolis): `athHill1` dome `H(1-q)²` / cone / mesa (`:212-215`), colour only `lerp #7f9a5a` by height (`60_city_build.js:106`) and `M.rock` for the Akropolis.
- Backdrop ridges: Athens only, `athRidge` (`src/60_city_build2.js:150-155`): 4 ranges (Ymittos/Penteli/Parnitha/Aigaleo) as one silhouette strip each, **2 vertex colours** (top #8f8aa8, foot #d9d2c6), height jitter ±15 %, `MeshBasicMaterial fog:false`. Frankfurt has no backdrop ridge.

**Water** `waterMat()` (`src/60_city_build.js:167-176`): MeshStandard #2b7fb0, roughness .14, metalness .3; 3-sine vertex waves (±0.8 m, same function drives the boat), ripple normal perturbation (2 sine products), `aBank` attribute = distance to bank: quay foam `smoothstep(6,0,bank+sin·1.4)`, crest highlight, mid-river lightening over 70 m. Missing: shallow→deep colour ramp near the bank (only a darkening ×.72 at the edge), fresnel sky reflection, flow/foam streaks, sparkle, any turquoise. Frankfurt: Main + Osthafen basin. Athens: none.

**Sky / fog** `SKY_FS` (`src/10_core4.js:231`), values set in `GFX_light` (`src/98gx_gfx.js:25`): top (.004,.045,.40), mid (.025,.16,.72), horizon fra (.48,.68,.92) / ath (.62,.66,.78), brick clouds. Fog `FogExp2` density .00016 (high) / .00024 / .00032, colour `#b9cff0` fra / `#cfd6e2` ath. Good. Gap: land colour does not blend toward fog colour with *height/distance* tint, so far hills are saturated green against pale sky (shot 1).

## 3. Benchmark: how 2K Drive and similar games get variety (research, ~10 min)
Search results were mostly dev blogs/forums, not GDC slides; claims below are marked source / mine.
| technique | what it is | source | cheap way here |
|---|---|---|---|
| Biome identity by colour family | Each region has its own 2-3 colour family (2K: sandy canyon/Arizona desert in Big Butte, grassy knolls in Turbo Acres, swamp, haunted) so you know where you are from colour alone | [2K Bricklandia biomes](https://lego.2k.com/drive/features/biomes/), [racinggames.gg biome list](https://racinggames.gg/article/lego-2k-drive-map-every-biome-in-bricklandia), artists' [Big Butte Rock Kit](https://www.artstation.com/artwork/8bDl4Q) | `BIOMES` already has rects: add a palette table per `g` (item 1/5) |
| Splat/ruleset terrain materials | Forza Horizon: artists paint a splat map of materials; rulesets blend into each other; the splat also drives vegetation placement | [FH4 terrain (Hughes)](https://www.artstation.com/artwork/0XEwB8), [FH5 terrain texturing](https://www.artstation.com/artwork/zDzELq) | no splat texture: procedural weights in the fragment shader from world-xz fbm + height + slope (item 1, 3) |
| Height + slope blending | grass↔rock by `dot(normal, up)`, snow/alpine by height, smoothstep bands | [GameDev.net slope thread](https://gamedev.net/forums/topic/337540-glsl-terrain-shader/3198175/), [pinwheelstud low-poly gradients](https://www.pinwheelstud.io/post/how-to-color-low-poly-terrain-with-gradients-and-curves), [Unity height blend](https://timcoster.com/2020/09/03/unity-shader-graph-procedural-planet-tutorial/) | `onBeforeCompile` on the 2 terrain materials; `vNormal`/`normal.y` is free |
| Break up tiling with macro noise | world-space low-frequency noises (two octaves) tint the albedo so a 14 m tile never reads as a repeat; warped/noisy transitions | [wave_forge ground shader issue](https://github.com/AntonTegnelov/wave_forge/issues/322), [Godot procedural blend](https://godotshaders.com/shader/procedural-terrain-texture-blending-shader/) | value-noise `fbm` in GLSL (3 octaves, ~12 ALU), no texture |
| Stylised water | depth tint (shallow turquoise → deep blue), foam where water meets geometry, fresnel rim, two panning normal maps instead of big waves, foam lines moving inward with noise | [Hali Savakis stylised water](https://halisavakis.com/my-take-on-shaders-stylized-water-shader/) (formulas: `foamDiff=saturate((sceneDepth-surfDepth)/thr)`, `fresnel=pow(1-saturate(dot(N,V)),p)`), [BotW-style edge discussion](https://forum.unity.com/threads/solved-fresnel-edge-shader-zelda-botw.568684/), [D. Ilett stylised water](https://danielilett.com/2020-04-05-tut5-3-urp-stylised-water/) | we already have `aBank` (= distance to bank): use it instead of a depth texture; fresnel from `vViewPosition`; foam bands = `step(noise, f(bank - t))` |
| Painted distance (BotW) | Distant objects wash out deliberately; bright gouache palette, plein-air colour | [BotW aesthetics thread](https://www.zeldadungeon.net/forum/threads/botw-aesthetics.56689/) (fan source, opinion) | colour the ridges and far ground toward fog colour by distance in the same shader (item 7) |
| Cheap grass/flower scatter | GPU-instanced blades/flowers, wind from a scrolled 2D noise | [Ghost of Tsushima grass note](https://x.com/StylizedStation/status/1688939450317807617), [GLSL grass triangles](https://medium.com/antaeus-ar/making-grass-with-triangles-in-glsl-using-three-js-e106771a71ff) | NOT blades: ~6000 flat 2-tri flower quads or 1x1 brick studs in ONE `InstancedMesh`, cell-hash placed in a ring around the camera (item 6) |
Not found: Mario Kart 8 / Hot Wheels / Sonic Racing environment tech breakdowns (searches returned only fan/stock pages); the Mario Kart look rule I use is mine: saturated hue shifts per zone, not per-pixel realism.

## 4. Top 8 changes, ranked by look-gain per cost
All shader / vertex-colour / instancing; no new textures >256²; total new draw calls ≤ +6 (budget 5 % of ~540-700 = 27-35). Put shared helpers in ONE new module `src/98ev_env.js` (add to `src/ORDER`), flag `TUNE.envVar` default OFF until the TAG passes, `?env=1/0` override.

**1. World-space noise colour on the outer-land ground (biggest gain, ~40 ALU, 0 calls).** `src/60_city_build.js` `worldGroundBuild` (`:103-106`): keep `tm`, add `ENV_patch(tm, {scales:[900,260,70]})` via `onBeforeCompile` (varying `vWP` from `modelMatrix*position`). Fragment: `n = .5*vn(p/900)+.3*vn(p/260)+.2*vn(p/70)` (value noise, `fract(sin(dot(i,vec2(127.1,311.7)))*43758.5)`), `diffuseColor.rgb *= mix(vec3(.80,.88,.72), vec3(1.18,1.12,.82), n)` then 25 % of the cells get a second palette. **Target palette (Frankfurt meadow):** lush `#6fbf3a`, deep `#3f8f30`, sun-dry `#c8c455`, clover-yellow `#d9cf5a`, damp-dark `#2f7a32`; Athens (dry Mediterranean): `#b9b070`, `#9aa656`, `#d2b673`, `#c9a066` (earth), `#7f9a5a`. The grass.png base `#5aa83a` must be desaturated to ~`#8fae5a` first (it multiplies everything and is why every lawn is the same neon lime). Kills the 14 m tile repeat (octave 70 m) and the 250 m cell blocks (replace `hsh` colour by `fbm`; keep the biome lerps as weights).

**2. Same patch on the city ground + lawns.** `src/60_city_build4.js:13` (`M.grass` Frankfurt `gm('grass',0x7aa860)`, Athens `athGrassTex()`), parks `G(...,M.grass,...)` `:67`. Call `ENV_patch(M.grass,{scales:[300,80,22]})` (smaller scales: parks are 50-200 m). Add 2-3 mown stripes (`step(.5, fract(dot(p.xz, dir)/6))·0.06` brightness) on park-sized plates only. Target: park lawn `#7fc43f` / `#6ab035` stripes; Athens park `#a9b565`/`#98a85a`. Kills the studded neon lawn in shot 6 (drop the stud-like dab frequency by sampling the texture at ×0.5 UV in the patch).

**3. Mountains: shape + slope/height colour (the "ugly mountains").** (a) `tauRaw` (`src/53_terrain_roads.js:257`): add a ridged octave: `h += s·(38·R(u/820, v/1100) + 11·R(u/210, v/260))` where `R(x,y)=1-|2·vn(x,y)-1|` (ridged value noise, cheap sine-hash); keep max ≈ 110 m, gradient on drivable parts ≤ 0.25 (roads drape via `tauH`, so re-run the Taunus road checklist; ship behind the flag). Same octave added to `athHill1` domes for Lycabettus/Filopappou (+6 m ridge detail, cliff band at `q>.7`). (b) `taunusBuildG` colour (`src/60_city_build.js:74`) and `HUB.tauMat` (`src/60_city_build4.js:6`): **remove `flatShading:true`**, replace the 3 height stops by a shader: `slope = 1-normal.y` ; `rock = smoothstep(.28,.5,slope + .15*n)` → `#8c8478`/`#a69d8a` (layered strata: `step(.5, fract(p.y/9+n))*.08` darker bands); forest band `h<45` → `#3f7a3a`; meadow `h 45-70` → `#8cbf4a`; alpine crown `h>85` → `#e8e2cc`, optional snow cap `#f4f8ff` only >100 m. Athens: `lerp #7f9a5a` → limestone `#cfc4a8` on slope (Lycabettus is bare rock), olive/pine green `#6b8a3e` on flats. Same material patch on the Berg hill so it stops being a green blob (shot 4).

**4. Water: depth tint + fresnel + foam bands (`waterMat`, `src/60_city_build.js:167`).** Use `aBank` (0 at bank → 70+ mid): colour ramp `bank<4: #5ad1c8` (turquoise shallow) → `bank 4-25: #2fa3c9` → `bank>60: #14507e` (deep) replacing the `×.72/×1.12` lerp; fresnel `pow(1-saturate(dot(N,V)),3)` mixes toward sky `#bfe3ff` (sky reflection without envmap cost); foam: two moving bands `foam = step(noise(vWP.xz*.25 + uT*.2), .35) * smoothstep(14,2,bank)` plus the existing quay foam; sparkle `pow(max(dot(reflect(-V,N),sun),0),60)*.6` (sun dir from uniform). Keep `wvH` waves (boat uses it). +0 calls. Athens: add a sea only if Alex wants a coast (separate item; a 2 km plane at y=-1.5 with this same material, ≤ +2 calls).

**5. Zone palettes and crop/field patchwork (biome identity).** `BIOMES.g` (`src/60_city_build.js:98-101`) → a palette table `ENV_PAL[g]` read by item 1: `field` (Wetterau): 40 m **stripes** by `floor(dot(p.xz,dir)/40)` hash → wheat `#d9c45a`, rapeseed `#f2d22e` (rare), young green `#8fbf3f`, ploughed `#b58a55`, grass `#6fbf3a`; `forest` (Stadtwald): dark `#2f6a34`; `air`: short grass `#9fc060`; `town`: plain; `hill`: item 3. Athens `RF.biomes` zones: `villa` olive `#8a9a4e`, `quarry` `#d8c6a2`. Costs only the table plus 1 uniform array; this is what makes "somewhere else" read from the road.

**6. Flower + grass-tuft scatter in the open (1 call).** New `ENV_flowers` in `src/98ev_env.js`, patterned on LF's `InstancedMesh` (`src/98lf_lively_fill.js`): ONE `InstancedMesh` of 5000 two-triangle cross quads (0.5 m, colours `LF_FC` `#ffd12c #ffffff #f28ac0 #ff8a1c #d8302a #3f7fe0`) + 2000 tufts (`#4f9a36`), placed each time the player moves 40 m: ring 8-120 m around the camera, cell hash on a 6 m grid, density `smoothstep(.55,.8,fbm(p/35))` so they come in **patches** (meadow flowers), only where ground type is grass (outer land + park zones), y from `TR_Y`. +1 draw call, ~12 k tris. Also lets LF flower colours appear outside the city.

**7. Aerial perspective + layered ridges.** (a) Fragment tint in `ENV_patch`: `diffuseColor.rgb = mix(c, fogColor*1.05, smoothstep(600.,3000.,dist)*.55)` so far hills desaturate toward `#b9cff0` (fra) / `#cfd6e2` (ath) before the fog applies (BotW-style wash-out, cheap). (b) `athRidge` (`src/60_city_build2.js:150`): 3 layers per range (D 2300/2100/1900, heights ×1/.8/.6), colours foot `#d9d2c6` → mid `#b9a9c0` → top `#8f8aa8`/`#a79bc0`, per-vertex noise on top edge (replace `.82+r()*.3` by 3-octave sine) + a light snow/limestone tint `#e8e2d8` on peaks > 85 % height. (c) Frankfurt backdrop: reuse `athRidge` with 2 ranges (Taunus NW, Odenwald S, `ang` 1.2-1.6°, colours greener `#7fa08c` top). +2-3 calls.

**8. Foliage colour zones (autumn/spring variety) + the existing size mix.** `src/60_city_build.js:96` (Taunus trees, `TC` 4 greens `#2f6a3a #3f7a34 #2a5e34 #4f8a36`): per-tree colour from `fbm(p/400)`: 70 % greens, 20 % `#d9822b`/`#c9452a`/`#e8b83a` autumn patches (forest zone only), 10 % pale spring `#8ccf4a`. Same for Stadtwald/Wetterau hedges and the LDraw trees (`src/98as_assets.js` instance colour). Also switch ON `TUNE.cvFol` (size/hue mix, already built: `docs/CITY_VARIETY.md` §4). 0 calls (instance colour only).
