# Emberclimb handoff (W332, branch shelf/W332-emberclimb)

Deck-building tower climb. Slug `emberclimb`, source `games-src/emberclimb/`. Not deployed.

## What plays
- 4 heroes (Ember Warrior: Strength, Venom Rogue: Poison + Shivs, Orb Automaton: Lightning/Frost/Dark orbs, Stance Monk: Wrath/Calm), solo or 2-hero hot-seat (shared map, gold, relics, potions; each hero has own deck, HP and turn; enemy HP x2 with two heroes).
- Act 1 only: branching map (9 floors + boss, floor 5 treasure, floor 9 rest), monster / elite / rest / shop / event / treasure / boss rooms. 3 Act-1 bosses (one per run).
- Turn: draw 5, 3 energy, attacks / skills / powers, X-cost cards, exhaust, unplayable status and curse cards, block, Strength / Vulnerable / Weak / Frail / Poison, d6 dice on cards, relics, events and the Fortune Die potion (1-2 low, 3-4 middle, 5-6 high).
- Enemies show intents (attack with real damage after modifiers and target hero, block, buff, debuff, sleep). Their AI = the intent patterns in `src/data.js` (cycle or random, ritual, wake-up, "skill played" rage).
- Rewards: gold, pick 1 of 3 cards (or skip), potions, elite relic, boss relic choice of 3. Rest: heal 30% or upgrade. Shop: 6 cards, 2 relics, 2 potions, card removal.
- Bot (`src/ai.js`): used by the tests only (no teammate AI needed).

## Files
- `src/data.js` all content (cards 109, enemies 14, relics 19, potions 9, events 6). `src/engine.js` rules (JSON-safe `G`, `validMoves`, `performMove`, `step`, `settle`, `checkInvariants`). `src/ui.js` DOM UI. `src/scn.js` scenarios for the shell test runner. `build.py` -> `emberclimb.html` (gitignored).
- Tests: `node rules-test.js [games]` (targeted rule checks + bot games), `sweep.js` (the build-all gate), `NODE_PATH=/opt/node-tools/node_modules node smoke.js` (real taps phone 390x763 + PC 1440x860).

## Assets
Every picture is a slot (`A(stem)` in `src/ui.js`): `games/emberclimb/media/<stem>.webp` is drawn when present, else a code placeholder. `assets.json` (220 items: wave 1 = 54, wave 2 = 153, wave 3 = 13) is generated by `node tools/gen-assets.js` (also writes `ASSETS.md` and `games-src/next-wave/flow-2d/emberclimb/prompts-wave{1,2,3}[-tall|-wide|-square].json`). Re-run it after adding any card/enemy/relic. `asset-registry.py` only supports nightrun, so it was not run.
Loader proven with 3 dummy files (hero portrait, card art, background) and the dummies removed.
