# Tidewake (plays like Tsuro of the Seas + Veterans of the Seas) — build plan
Public shelf game. Original names/art. Art direction: "Painted sea chart": warm 3D tabletop, teal ink-wash ocean board with gold compass rose and inked coastline border, carved wooden junk ships with paper sails (8 colours), glowing foam wake trails along the paths, leviathans = sea serpents/dragons rising from the waves with scales catching light. 2D fallback board for jsdom/software GPUs.
Decisions (planner): board 6x6 squares, edges numbered 1-6 (2 dice -> square); ships start on edge marks; 56 currents = 35 distinct 8-port tiles + 21 duplicates spread evenly (document choice); leviathan tiles: our own arrow layouts (arrows numbered 1-6 on 8 directions, random rotation on placement) marked GUESSED; hand 3; turn per rules-notes.md; expansion "Deepwater Perils": Rift Gate (portal), Rogue Wave (tsunami, gold+blue marker), Maelstrom (whirlpool), Deck Cannon x5, each switchable; variants: solo, easy solo, teams.
Names: currents (wake tiles), leviathans (daikaiju), junks (ships), Rift Gate, Rogue Wave, Maelstrom, Deck Cannon.
Folder: SP/tots/game (src/engine.js, data.js, ai.js; kit/; audio/); follow skill references (architecture, layout-shell, newcomer-ux, graphics-aaa, audio-perf, online-p2p, testing).
Stages: 1) engine+AI+tests | 3D kit | audio (parallel). 2) UI integration (board-first, guided first game, coach, PerfHUD). 3) online P2P (hand tiles are hidden info; deck order + seed hidden). 4) newcomer review + rules audit (Opus planner reviews). 5) shelf + cover + push + live check.
