# Tidewake 3D kit: report and API
Files: `kit.js` (global `TWKit`, 142 KB, plain script, needs Three r158 UMD for 3D only), `demo.html` (self-contained, 784 KB, built by `python3 build.py` from `demo-src.html` + `parts/p*.js`), `shoot.js` (Playwright harness), `dbg.js` (one-off scenario screenshot), `test-jsdom.js` (2D fallback test, ALL OK), `ASSETS.md`.
Art: "Painted sea chart": teal ink-wash board with seigaiha wave pattern, parchment coast frame with hand-drawn wobbly coastline and graticule ticks, gold compass roses, medallions 1-6 on all four edges, gold start marks on all 48 outer ports; glossy sea-tile squares with glowing foam curves (+ flowing foam dots); carved wooden junks with battened paper sails in 8 colours.
Coordinates: squares (c,r) 0..5, c right, r down. Ports 0..7 clockwise from top-left (0,1 top L->R; 2,3 right T->B; 4,5 bottom R->L; 6,7 left B->T). Rotating a tile 90 deg cw adds 2 to every port. Arrow dirs: 0=N,1=NE ... 7=NW. Edges are 'top'|'right'|'bottom'|'left' with index 1..6 (top/bottom L->R, left/right T->B).
Quality: Auto/High/Medium/Low (localStorage `tw_gfx`). High: dpr 2, 2048 shadows, PBR clearcoat, flow dots, full particles. Medium: dpr 1.5, 1024 shadows. Low: dpr 0.75, no shadows/env/fog/flow, 40% particles. Auto = Medium on phones, High on desktop, steps down one level after ~3 s of bad frames.

## API (all async calls return Promises; every call works in both 3D and 2D)
- `TWKit.init(canvas,{fallback:divEl, quality, force2D, onHover(p,ev), onClick(p,ev), preserveDrawingBuffer, fonts:false}) -> {ok,mode:'3d'|'2d'}`; `TWKit.ready` (fonts promise); `resize(w,h)`; `dispose()`; `supported()`.
- Quality/perf: `setQuality('auto'|'high'|'medium'|'low')`, `getQuality()->{pref,active,mode}`, `stats()->{mode,quality,frameMs,renderMs,fps,draws,triangles,frames}`, `resetStats()`, `setHooks({onFrame(stats) every 30 frames, onQuality(q)})` (PerfHUD), `setSpeed(x)`, `isAnimating()`, `advance(sec)` (deterministic stepping for tests), `renderOnce()`.
- View: `setView({tilt,yaw,zoom,reserve:{l,r,t,b} (fractions of viewport hidden under UI, e.g. dock),region,immediate})`, `focus(c,r,zoom)` / `focus(null)` to return, `shake(amp,ms)`.
- Events for audio: `TWKit.on(name|'*',fn)` / `off`: splash, place, spawn, sail, collide, sink{how}, destroy, dice{bounce}, cannon, rift, wave, whirl, roar.
- Helpers: `layouts()` (the 35 distinct 8-port tile layouts), `rotate(paths,k)`, `exitPort(paths,p)`, `neighbour(c,r,port)`, `trace(tilesMap{'c,r':paths},c,r,port)->[{c,r,from,to}]`, `edgeSquare(edge,index)->{c,r,ports}`, `portEdge(c,r,port)`, `SHIP_COLORS` (8).
- Tiles: `placeTile(c,r,{paths,rot,animate})` (drops, splash), `removeTile`, `destroyTile(c,r)` (crack, shatter, foam; also works on leviathan tiles), `clearBoard()`.
- Leviathans: `placeLeviathan(c,r,{arrows:[{dir,n}],kind:'serpent'|'dragon',rot,animate})` (tile drops, creature coils up; arrows+numbers printed on tile), `removeLeviathan`, `leviathanRoar(c,r)`.
- Ships: `addShip(id,{color:0..7|name,c,r,port,splash,cannons})` (spawn splash), `moveShip(id,steps,{dur,speed})->{c,r,port}` (eased glide along the in-tile curves, wake trail, bobbing; steps from `trace`), `setShipAt`, `collide(a,b)`, `sinkShip(id,{how:'crash'|'leviathan'|'maelstrom'|'wave'|'cannon',at:{c,r},keep})`, `reviveShip`, `removeShip`, `setCannons(id,n)`.
- Dice: `rollDice([{kind:'gold'|'blue',value}],{at:{x,z}})->values` (tumble, bounce, land on given faces; right of board in landscape, below in portrait), `clearDice()`.
- Expansion: `riftGate(c,r,on,{color:'violet'|'cyan'|'gold'})`, `riftWarp(id,fromSq,toSq,{port,heading})`, `maelstrom(c,r,on)`, `rogueWaveTile(c,r,on)`, `rogueMarker(edge,index,on)`, `highlightLine({row}|{col}|null)`, `rogueWaveSweep({edge,index}|{row|col,dir})`, `cannonShot({from:id|{c,r},to:id|{c,r},hit})`.
- Picking: `hover(x,y)` (gold square glow; returns pick), `pick(x,y)->{kind:'ship',id}|{kind:'start',c,r,port,edge,index}|{kind:'square',c,r,tile,leviathan}|null` (client coords; ships > start marks > squares), `setLegal([{c,r}])` pulsing teal frames, `ghost(c,r,paths,{rot,valid,enter:port,trace:[steps]})` translucent tile + gold traced path (pass `trace` from `TWKit.trace` over tiles+ghost for multi-tile paths), `ghost(null)`.
- Cards (for the dock): `cardSVG(paths,{rot,size,selected,uid})`, `cardURL(...)` (data URL for `<img>`), `leviathanSVG/leviathanURL(arrows,{rot,...})`. Rotatable via `rot`.
- 2D fallback (no WebGL, jsdom, or `?2d`): painted-chart SVG in `fallback` div, same API/state, clickable (onClick/onHover/pick), animated ships/dice/effects, `reserve` honoured. `getState()` dumps tiles/leviathans/ships.

## Test results
Screenshots in `shots/`: 1366x768 (High), 390x844 (Medium), close-ups (leviathan, ships, gate, whirlpool, dragon), fx (sail, crash, sink, dice, cannon, wave, warp, destroy, roar, spawn), 2d-1366x768, 2d-390x844. Looked at all; fixed: slab z-fighting hid the chart, over-bright washed tiles, tiny ships/serpents, camera off-centre under dock, dice too small/camera jump, icy wave colours, gate pedestal tint.
Perf (SwiftShader software GL, 1366x768, so absolute numbers are pessimistic): High ~730-1700 ms/frame, Medium ~330-1200 ms, Low 167 ms (6 fps) with 262 draws / 31k tris; on a real GPU CPU render time is 4-10 ms. jsdom 2D test: 14/14 ok. Console: no errors (only the blocked Google Fonts request in the harness).
Known rough edges: Rogue Wave crest is a chunky extruded profile (reads as a wave from the side, plain from above); leviathan heads are small from the default overview camera; High has no bloom pass (glow is emissive maps + additive particles).
