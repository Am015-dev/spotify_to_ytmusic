# Tidewake kit assets
No external assets. Everything is procedural (canvas textures, geometry, GLSL, SVG), original art, so no licence obligations.
| What | Source | Licence |
|---|---|---|
| Three.js r158 UMD (inlined by build.py) | npm `three` | MIT |
| Fonts (optional, Google Fonts link with serif fallback): IM Fell English SC, Cormorant Garamond | fonts.google.com | OFL |
| Everything else (board chart, tiles, junks, leviathans, dice, portal, whirlpool, wave, cannon, particles, cards) | generated in kit.js | original |
