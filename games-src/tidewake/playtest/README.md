# Tidewake blind playtests (Oct 2026)

Six blind testers, two per round, each a new agent with no repo access, on a 390x763 phone screen through
`games-src/scripts/drive-serve.js`. One tester per round was **casual** (skims, taps the big button, takes the guided
game). The other was **impatient** (skips the tutorial).

| Round | Build | Casual | Impatient | Average |
|---|---|---|---|---|
| 1 | live `games/tidewake` (before) | 2.5 | 3 | 2.75 |
| 2 | first clarity pass | 2.5 | 2 | 2.25 |
| 3 | second clarity pass | 3 | 3 | 3.0 |

The logs are copied here unchanged. The screenshot paths in them point into the session scratchpad and were not
kept (about 300 PNGs). The final build (after round 3) has more fixes; see `../CLARITY-REPORT.md`.
