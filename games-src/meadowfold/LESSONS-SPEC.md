# Meadowfold scenario lessons: spec for src/lessons.js

Build src/lessons.js: six scenario lessons on the shared engine GXST (read games-src/shell/GXST.md, games-src/orch/TUTORIAL-SPEC.md section 2, and copy the structure of games-src/tidewake/game/lessons.js: IIFE, `if(!window.GXST)return`, ready() poll, stack(sp) helper, lessons array, hook, go(), GXST.init). ES5 only, no emoji. Game facts: engine is games-src/meadowfold/src/engine.js (global G, E; E.apply, E.score(seat), E.nb(side,key), E.moves()), UI in ui.js (newGame(o), render(), act(m), UI.mode, UI.fast, nextActor). Board side A keys are 'c,r' (cols have 5,4,5,4,5 cells). Token colours: water mount trunk leaf field build. Tokens must be conserved: stack(sp) calls newGame({np:2,humans:1,ai:'easy',side:'A',spirits:false,seed:11,seats:[{name:'You',ai:null},{name:'Rival',ai:'easy'}]}) with UI.mode='quick' (NOT 'tut'), then rebuilds the position by hand: seat0.board = sp.board (map key -> array of colours), G.central = sp.pockets (3 pockets of 3 tokens, others empty arrays, same length as before), G.turn.hand = sp.hand and G.turn.took = sp.took (or -1), seat0.cards = sp.cards, G.row = sp.row (card ids), G.deck = every other card id 1..32 not in row/cards. Then recompute G.bag = copy of MF.BAG minus every token on any board, in central and in hand (so E.check() returns null), G.box=0; then render() and return a Promise that resolves after ~300 ms. Wrap save()/localStorage so lesson games never overwrite the real save while GXST.active() (like tidewake lessons.js `saveAll` wrap; here the function is save()). GXST.init({game:'meadowfold', scenarios:lessons, keepClear:['#central','#map','#endB','#strip','#dockbody'], settled:function(){return typeof G!=='undefined'&&G&&!UI.busy&&G.cur===0&&!G.over;}}). Also support the URL param ?lesson=<id>: after init, if present call GXST.start(id) (hide the #start title screen first by setting its hidden=true). Each lesson judges the REAL state; success must also require G.turn.hand.length===0 where the lesson is about placing. Lessons (id, title<=3 words, goal<=12 words, par, rule, nudge/show hints, debrief, fail message naming the consequence): (1) take 'Take a pocket': pockets P0 [water,field,build], P1 [mount,mount,mount], P2 [trunk,leaf,water]; empty board; goal 'Place three grey tokens in one turn.'; success: seat0 board holds >=3 mount tokens in total and hand empty; fail: took>=0 and took!==1 -> 'That pocket has no three greys; a pocket is taken whole.'; rule 'Take one pocket, a whole pocket of 3 tokens, then place all three.' (2) stack 'Stack greys': start already took pocket (hand [mount,mount,mount], took 0); board empty; goal 'Build one peak three high.'; success: some hex has 3 mounts; fail: hand empty and no hex of 3 -> 'Grey stacks up to 3 on one hex; you spread them out.'; rule: 'Grey stacks up to 3 on grey.' (3) tree 'Grow a tree': hand [trunk,trunk,leaf] took 0, empty board; goal 'Grow a tree worth 3 points.'; success: E.score(seat0).trees>=3 and hand empty; fail: hand empty and trees<3 -> 'A leaf on bare ground is only a 1 point sapling: trunk first, then leaf.'; rule 'Leaves go on 0-2 trunks; a tree of height 2 scores 3.' (4) fields 'Fields': hand [field,field,mount] took 0, empty board; goal 'Score 5 points from fields.'; success: E.score(seat0).fields>=5 and hand empty; fail: hand empty and fields===0 -> 'Fields score only when 2 or more touch.'; rule '5 per group of 2 or more fields.' (5) river 'River': board has one water on '2,2'; hand [water,water,water] took 0; goal 'Score 8 points with one river.'; success: E.score(seat0).water>=8 and hand empty; fail: hand empty and water<8 -> 'Only the longest connected river scores: keep your water in one line.'; rule 'Side A scores the longest river path: 2, 5, 8, 11, 15.' (6) animal 'Settle an animal': board '2,2':['leaf'] and '1,1':['water']; took 0 hand []; row [5,1,3,10,12]; seat0.cards [] ; goal 'Take a card that fits, then settle its animal.'; success: E.score(seat0).animals>=2; fail: seat0.turns>=1 (turn ended) -> 'The turn ended with no animal home: take a card whose habitat you built, then tap Home ready and the hex.'; rule 'When a card says Home ready, tap it and then the glowing hex; the animal moves in and scores.' Reuse the wording of TUT_STEPS in games-src/meadowfold/src/tutor.js for rule/hints where it fits. Hints: [nudge text with no answer, {say: answer text, target: a CSS selector string like '.pocket[data-pocket="1"]' or '#map .hx.glow'}]. moves(): count of act() calls during the lesson (wrap via the E.apply wrapper active only while GXST.active()). Do not touch colours, buttons or skin.css. Export window.MFL = {L, stack, lessons} for tests.
