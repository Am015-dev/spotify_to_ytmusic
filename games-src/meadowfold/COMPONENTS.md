# Meadowfold components (every piece, count and effect)

| Component | Count | Effect |
|---|--:|---|
| Water token (blue) | 23 | river (side A) / splits islands (side B); never stacks |
| Mountain token (grey) | 23 | stacks to 3; 1/3/7 when touching a mountain |
| Trunk token (brown) | 21 | lifts leaves: 1 or 2 under a leaf |
| Leaves token (green) | 19 | tree top; tree 1/3/7 by height |
| Field token (yellow) | 19 | 5 per group of 2+; never stacks |
| Building token (red) | 15 | on one grey/trunk/red; 5 with 3+ colours around |
| Pouch | 1 | random draws |
| Central board | 1 | 5 pockets (solo side 3) |
| Valley board | 4 (one per seat) | side A 23 hexes river / side B 25 hexes islands |
| Animal cards | 32 | listed below |
| Spirit cards | 10 | listed below (variant) |
| Animal cubes | 75 | unlimited in play |
| Spirit cubes | 4 | one per kept spirit |

Pattern notation: first hex, then the direction from the previous hex (flat-top: N, NE, SE, S, SW, NW); any rotation, no mirror.
