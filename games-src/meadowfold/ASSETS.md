# Meadowfold assets (licence log)

Style: paper-cut diorama, all drawn in code (SVG in src/art.js): tokens, stacks, board, hills, cards, buttons. No downloaded pictures,
no fonts beyond the shelf's own (Alegreya Sans, OFL, inlined by build-all), no sound files (WebAudio paper rustles and chimes in src/ui.js).
