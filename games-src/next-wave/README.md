# Next wave: prompt files for the laptop

Generated by `python3 games-src/scripts/make-wave7.py` (data: `games-src/scripts/wave7_data.py`, plan: `games-src/VARIETY-PLAN.md`). 939 paintings and pose images in 2D waves (Wave 7, 8, 9 ...) and 191 source paintings for 3D in their own track (3D wave A, B ...).

## How to run them

1. Copy the folders `flow-2d` and `flow-3d` from this folder into the laptop's game-art root (the folder that already holds `flow-2d` and `flow-3d`). They only add `prompts-*.json` files; nothing existing is overwritten.
2. Run **one wave per day**: every wave is at most 380 images, the laptop limit per day (`limit` in `games/asset-viewer/flow.json`). Start with the lowest wave number; the files are ordered by priority, top picks first. A character's whole pose set is in one wave, so its poses stay consistent.
3. In each game folder the files for a wave are `prompts-wave<N>.json` (1:1) and `prompts-wave<N>-wide|-43|-34|-tall.json` (16:9, 4:3, 3:4, 9:16). Run each file with its own ratio; every card already carries the game's style block.
4. 3D source paintings are `flow-3d/<game>/prompts-3d-wave<A|B|..>.json` (about 40 per wave, own track, 1:1, light-grey background). `prompts-3d-all.json` lists all of them with the target glb path.
5. Poses and cut-outs ask for a flat chroma colour background: cut them out with `python3 games-src/scripts/cutout.py` (see the note inside each file).
6. The laptop viewer (`flow_status.py`) labels the files by wave and shows the unmade ones as planned. The static copy is refreshed with `python3 games-src/scripts/viewer-plan.py`.

Wave 9 has only 183 images: on that day the whole 3D track (191) fits in the same 380, so run the 3D waves with it.
