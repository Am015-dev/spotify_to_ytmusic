# Assets (Hollowbough kit)
No external assets. Every illustration, icon, token, texture and filter is generated procedurally (SVG strings, feTurbulence/feDisplacementMap filters) in kit.js, original to this project.
Fonts: none embedded. System serif stack: Palatino Linotype, Book Antiqua, Palatino, Iowan Old Style, Hoefler Text, Georgia, DejaVu Serif, serif. No Google Fonts, no OFL file needed.
Names/art are original; no Everdell art, layout or card frame is imitated.
