# Shipwreck Isle: rules checklist

Every rule of the base game that the engine has to apply, numbered. `logic-test.js` has **one headless assertion per numbered rule** (rules marked "not testable" are the exceptions, with the reason). This file is generated by `node logic-test.js --md`; edit the rule table in `logic-test.js`, not this file.

- **Rules listed:** 278  ·  **asserted by logic-test.js:** 275  ·  **not testable headless:** 3
- Run: `node logic-test.js` (quiet). A failure prints one line: `FAIL <rule>: expected <rulebook>, got <engine>`. `node logic-test.js A5 H1` runs single rules.
- The tests set up a state with the real engine (`newGame`, `place`, `FN.go`, `FN.weather`, `FN.night`, `useSkill` ...), act, and compare the exact result. Dice are forced by replacing the dice face tables, never left to chance. They do not use the older builders' tests (`rules-test.js`, `sweep.js`) as evidence.

## Where the rules come from

1. **Base rules (setup, round phases, action order, dice, weather, night, characters, Friday and the Dog, discovery tokens, item effects, end of game):** a published player-aid summary of the 1st-edition English rulebook, read in full in this task, plus the player-count tables and character skill lists it prints. These are the rules marked in the tables below unless noted.
2. **Scenario rules (sections V):** the four scenario sheets as summarised in `rules-notes.md` and `data.js` (goal, round count, weather dice per round, totems, specials). They could not be checked against the sheets themselves, so the tests confirm that the engine does what the sheet summary says.
3. **Starting items and discovery token texts:** the item texts in `data.js` (what each token does), cross-checked with the discovery-token list in the summary where it prints one.

## Not covered (no source to check against, so no assertion would be evidence)

- The exact face counts of each of the 12 dice (rules-notes.md already flags the build wound die as a point where sources disagree). The tests force faces, they do not check the tables.
- The invention requirement lines (terrain, items, resources) for each of the 30 inventions, except where a rule above uses one.
- The text and numbers of each individual event, adventure and mystery card (about 200 cards). The engine generates card text from the same data it executes (`force.js` runs every card for crashes only).
- Character life-track lengths and the positions of the morale-down symbols (only the behaviour is asserted).
- Scenarios 4, 5 and the bonus sheet are not in the game.
