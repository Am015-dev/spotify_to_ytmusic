# Final Approach scenario lessons: spec (W709)
Engine: shell/gx-scenario-tutor.js (docs shell/GXST.md). Pattern: cauldron-fair/lessons.js. File to write: final-approach/game/lessons.js (ES5, IIFE, `if (!window.GXST) return;`).
The player is always the Pilot (seat 0, role 0). The co-pilot (seat 1) is scripted. Plain 2-seat flight on scenario `tt` (4-space strip, one traffic icon on space 3).

## stack(sp) helper (setup of every lesson; returns a Promise)
1. `try{GX.close()}catch(e){} try{GXH.setEnabled(false);GXH.hide()}catch(e){} closeRS(true)`-style calls: copy the closing calls used by `table()` in game/scn.js.
2. `UI.seed = sp.seed||7; newGame('vs', {scenario:'tt', role:0, level:'normal', tipsOff:true});` (do NOT pass tutorial:true). Then set `UI.coach.level='off'`.
3. Edit G directly, then rebuild the screen with `render()`:
   - `sp.pos` -> `G.pl.pos`; `sp.planes` (array of 4 counts) -> `G.planes`; `sp.axis` -> `G.pl.axis`; `sp.coffee` -> `G.coffee`; `sp.rr` -> `G.rrHand`.
   - `sp.sw = {lg:[..],fl:[..],br:[..]}` -> `G.pl.sw`; then `G.pl.aeroB = 4 + sum(lg)`, `G.pl.aeroO = 8 + sum(fl)`.
   - `sp.final` true -> `G.round = FA.D.rounds - 1 - G.row0` (so isFinal(G) is true; check how `D` is reached from the page, it is `D` in game scope) and re-read altitude from G.round.
   - Briefing: set `G.ready=[true,true]`, then call `FA.performMove`/the page's `commit(0,{t:'ready'})` path OR directly roll: simplest is `commit(0,{t:'ready'})` and wait until `G.phase==='place'` (the co-pilot readies itself through the AI). Then overwrite `G.dice[0][i].v` / `G.dice[1][i].v` from `sp.dice = [[p0..p3],[c0..c3]]` (all `u=false`), set `G.turn = 0`, `G.first = 0`, `G.events=[]`, `UI.evN=G.evN`, `render()`.
4. `L.on = true`, `L.n = 0` (the player's own moves; count in a wrapper around `commit` when `seat === 0 && m.t === 'place'`).
5. Co-pilot script `sp.cop = [[dieIndex, slotKey], ...]`: wrap `FA.AI.move` exactly like `tutAI` in game/src/ui12.js. While `L.on && GXST.active()` and seat 1, phase 'place', no pend, turn 1: the next entry is `sp.cop[number of co-pilot dice already used]` (`G.dice[1].filter(d=>d.u).length`); if that slot is free play it as `{t:'place', d, to, c:0}`; briefing: `{t:'ready'}`; else fall back to the normal AI.
6. Never save lessons over the real game: while `GXST.active()` make `saveGame` (game/src/ui1.js:72; the page has no autoSave) a no-op, like cauldron-fair/lessons.js does. No story card, no goal card, no hint bubbles.

## judge helpers
- `settled()`: `!UI.busy && !document.querySelector('.rfx,.fa-ro') && PX.tw.length===0 && PX.parts.length===0` (read how ui7.js `isAnimating` does it and reuse that) and the result screen not busy.
- Generic fail fallback for every lesson: `G.result && !G.result.win ? G.result.msg : false` (consequence message from the engine).
- Success is judged on the real G the moment the rule has played out; the round need not finish.
- Tap targets for hints: dice `#pz .die[data-s="0"][data-d="i"]`, slots `#pz .slot[data-slot="key"]`, coffee buttons `[data-a=cof][aria-label="One more"|"One less"]`, Ready/Roll `#acts [data-a=ready]`.

## The 7 lessons (id, title, dice are [pilot x4],[co-pilot x4])
1. `axis` "Level flight". Rule: the axis tilts by the DIFFERENCE of the two axis dice; 3 tilts is a spin. dice [[4,3,6,1],[4,2,5,3]], cop [[0,'ax1']]. Goal "Put the plane in level flight." success: G.slots.ax0 && G.slots.ax1 && G.pl.axis===0. fail: both axis dice down and axis!==0 -> 'The axis dice differ by N: the plane tilts N. Equal dice keep it level.'; spin is covered by the generic fallback. Hints: 'How far apart are the two axis dice?', show: die 0 (the 4) on slot ax0. par 1. debrief 'Same number on both axis dice: no tilt.'
2. `speed` "Engine speed". Rule: speed is the SUM of both engine dice; up to 4 stays, 5 to 8 moves 1 space, 9 or more moves 2. dice [[2,5,1,6],[4,3,2,6]], cop [[0,'en1']], pos 1. Goal "Move the plane exactly 1 space." success: pilot en0 and cop en1 down and G.pl.pos===2. fail: both down and pos!==2 -> 'Speed S: the plane moved N spaces.' (N = pos-1). par 1. Hints: nudge 'Add both engine dice. 5 to 8 moves one space.'; show die 0 (the 2) on en0. Win with 2 (sum 6) or 1 (sum 5); 5 and 6 fail (9, 10 -> 2 spaces).
3. `radio` "Clear the way". Rule: a radio die of 1 clears a plane on your own space; clear it BEFORE you move away or you collide. dice [[1,4,6,3],[4,3,2,6]], cop [[0,'en1']], pos 1, planes [1,0,0,0]. Goal "Fly to space 2 without a collision." success: G.pl.pos===2 && !G.result. fail: generic (collision message). par 2. Hints: nudge 'A plane sits on your space. Which die can clear it?'; show: die 0 (the 1) on slot ra0. Note the player's engine die: any of 4,6,3 on en0 with cop 4 gives speed 8/10/7: only 4 (8) and 3 (7) move 1 space; 6 gives 10 = 2 spaces (fine for this lesson, success only needs the plane to have left safely: use success `pos>=2 && !G.result`).
4. `gear` "Landing gear". Rule: each gear space takes a pair of values (1-2, 3-4, 5-6); a green gear raises the blue speed marker. sw {lg:[0,0,1],fl:[0,0,0,0],br:[0,0,0]} (third gear already down: 4 dice minus the mandatory axis and engine dice leave only 2 free placements), dice [[5,2,4,6],[3,3,3,3]], cop [[0,'co0']]. Goal "Turn the last two gear lights green." success: G.pl.sw.lg all 1. fail: some gear open and no unused pilot die fits any open gear (check each open index's `FA.D.gear[ix]` values; D reached as page global `D`) -> 'No die left fits the open gear. Match each die to its pair.' par 2. Hints: nudge 'Each gear space shows two numbers. Match a die to each.'; show die 1 (the 2) on lg0 (first lift it by tapping it; the existing UI taps die then slot).
5. `brakes` "Brakes in order". Rule: brakes take exactly 2, then 4, then 6, in that order. dice [[4,2,6,3],[3,3,3,3]], cop [[0,'co0']]. Goal "Set the brakes to 4." success: G.pl.sw.br[0] && G.pl.sw.br[1]. fail: (br[0] open and no unused pilot die with value 2) or (br[1] open and no unused pilot die with value 4) -> 'The 2 or the 4 is gone. The brakes need a 2 first, then a 4.' par 2. Hints: nudge 'The 4 will not fit yet. Which die opens the brakes?'; show die 1 (the 2) on br0.
6. `coffee` "Fix a die with coffee". Rule: a die on a Concentration space earns a coffee; spend it to change a die by 1. dice [[1,6,5,3],[3,3,3,3]], cop [[0,'ax1']], coffee 0. Goal "Set the first brake with coffee." success: G.pl.sw.br[0]. fail: br[0] open and impossible: let freeC = a free slot among co0..co2, maxC = G.coffee + (freeC && unused pilot dice count >= 2 ? 1 : 0); impossible when no unused pilot die has |v-2|<=maxC -> 'No coffee left to turn a die into a 2. Earn coffee on a Concentration space first.' par 3. Hints: nudge 'No die is a 2. How do you change one?'; show die 1 (the 6) on slot co0.
7. `touchdown` "Touchdown". Rule: landing needs gear, flaps, level axis, a clear strip, and engine speed no higher than the brakes. final round, sw {lg:[1,1,1],fl:[1,1,1,1],br:[1,1,0]} (brakes 4), pos 4, planes [0,0,0,0] (the airport is the last space), axis 0. dice [[3,2,6,5],[3,2,3,3]] (co-pilot 3 levels the axis, engines 2+2 = 4 = brakes), cop [[0,'ax1'],[1,'en1'],[2,'co0'],[3,'co2']]. The landing is judged at round end, so all 4 pilot dice must go down (solution 3->ax0, 2->en0, 6->br2, 5->co1). Goal "Land the plane." success: G.result && G.result.win. fail: generic (G.result.msg; the engine already says 'Too fast' or the failed checks). par 4. Hints: nudge 'Match the axis dice. Keep speed at or under the brakes.'; show die 0 (the 3) on ax0. If the pilot places no engine/axis the round just waits: success/fail judged on G.result. If isFinal landing needs extra setup (e.g. pos on last space) set pos = track size.

## init
`GXST.init({game:'final-approach', scenarios: lessons, qParent:'#gxst-slot' or default, keepClear:['#pz','#acts'] adapted so the card never covers the board (see phoneSlot below), settled: settled, phoneSlot: <selector>})`.
Open with `?lesson=<id>` (GXST.start(id)) or `?lessons=1` (picker); also a `Lessons` entry in the menu is the default button from GXST. Lessons are OFF by default except through that link/button.
`window.FALessons = {open: function(){GXST.picker()}}`.

## phoneSlot (shell change, option only; off when absent)
`GXST.init({phoneSlot: selector})`: when `innerWidth < 700` the card/chip is positioned inside the rect of the element matching the selector (a strip the game keeps free, e.g. the area between top bar and board), width clamped to it, never over `#pz`. When the selector is missing or hidden fall back to the current placement. Document in shell/GXST.md.

## Wording rules
No line over 12 words in goal/nudge/fail; no original game name; no emoji.
