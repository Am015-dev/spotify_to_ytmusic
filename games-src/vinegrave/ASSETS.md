# Vinegrave: pictures (2D only)

Every picture is a named slot. `media/<stem>.webp` fills it with no code change; until then a code-drawn placeholder shows. Manifest: `assets.json`.

Style block (in front of every prompt): Painterly 2D gouache illustration of a 1920s jungle expedition, hand-painted brush texture, warm greens, ochre and teal with soft diffuse light, gentle storybook shading, no 3D, no photo realism, no text, no letters, no numbers, no logos.

## Stem naming rules

- Lowercase letters, digits and hyphens only; one stem per picture, unique across the game.
- `card-<id>` for each card id in VD.CARDS (3 basic, 35 items, 35 artifacts), `card-back`, `card-frame-item|art|fear`.
- `site-<id>` for each VD.SITE id (`c-*` camp, level 1, level 2), `site-hidden-1|2` for face-down tiles.
- `guard-<id>` for each VD.GUARD id; idol pictures use the idol id as is (`idol-*`).
- `res-*` resources, `tr-*` travel, `explorer-0..3`, `token-*`, `temple-<points>`, `portrait-<name>`, `map-act1..3`, `fx-*`, `icon-*`.
- Card pictures are the picture area only: the game draws frames, names and numbers. No text or numbers inside any picture. Tokens, icons and UI pieces are one object on plain white.

## How to drop the finished pictures in (3 steps)

1. Generate each wave in Google Flow with `games-src/next-wave/flow-2d/vinegrave/prompts-wave<N>-ratio-<A>x<B>.json` (one file per wave and ratio; each stem is in exactly one file). Save each picture as `<stem>.png` (or .webp).
2. Put the files in `assets-inbox/vinegrave/` and run `python3 games-src/scripts/ingest-assets.py` (`--check` first = dry run). It writes `games/vinegrave/media/<stem>.webp`. (See games-src/PLAYBOOK.md, section Finished pictures from the owner.)
3. Tell the orchestrator; it runs the ingest report, wiring, then `build-all.py --deploy vinegrave`. The orchestrator also runs `python3 games-src/vinegrave/register-assets.py` once at merge time to add the slots to `next-wave/expected-assets.json`.

Fit rules: `bg` and `board` kinds are cover (cropped to fill), everything else is contain (never stretched).

## Temporary art (until the Flow pictures arrive)
38 slots (resource and travel icons, research tokens, all 15 guardians, all 12 idols) have temporary pictures made from game-icons.net
glyphs (CC BY 3.0; per-file list with authors: `temp-art/CREDITS.md`). They are not in the repo as pictures and never in games/ from this branch:
`node games-src/vinegrave/temp-art/temp-art.js` renders them into `assets-inbox/vinegrave/` (PNG), then `python3 games-src/scripts/ingest-assets.py`
puts them in `games/vinegrave/media/` at deploy. A later Flow file with the same stem simply replaces each one.
Credit line to keep in the shelf credits: "Icons made by Lorc, Delapouite and Caro Asercion. Available on https://game-icons.net, CC BY 3.0."
Not used: Tabletop Simulator workshop / print-and-play pictures (scans of the publisher's art); no fan art with an explicit reuse licence found.
