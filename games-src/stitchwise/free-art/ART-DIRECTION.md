# Art direction: stitchwise (free kit, round 2)

**Style:** real cloth, printed. Every patch fabric is a clean seamless print (gingham, dots, stripes, tartan, florals,
hearts, cherries, herringbone...) woven into a real CC0 linen scan (Poly Haven rough_linen thread detail), so patches read as
printed cotton at any size; the denim patch is the real denim scan with orange top-stitching. Prints follow the slot list's
colour/motif exactly; each repeat is seamless (512 px crop of a 1024 px periodic canvas).

**Notions:** spool tokens (teal = you, terracotta = opponent), golden four-hole button, wooden sand timer, rosette bonus:
flat vector at 4x, downsampled, one shared palette (cream #F5ECD6, gold #E2B23C, teal #2B8C8C, terracotta #C4623E).
Leather patch: real leather scan with cream stitching.

**Boards / scenes:** quilt mat = real linen on a real wood frame with a faint stitched 9x9 guide; time track = felt strip
with 54 notches; table = navy knit with a stitched border. Title and result screens: real wooden table with this kit's
own fabric squares, spools and buttons scattered around an empty centre for the title; win adds the rosette, loss is dimmed.
Story map = patchwork of green/yellow fabrics with a red running-stitch path between three rosettes.

**Portraits (round 2):** one family, Kenney Toon Characters 1. Each quilter is a recoloured SVG (shirt, and hair where it
helps: Wren silver, Aurelia gold, Marguerite dark) cropped to a bust, framed in a cream stitched medallion on a pale wash of
one of this kit's own fabrics, so portraits sit inside the same sewing-table world.
