# On-foot street stage: prompts for the picture tool

Generated by `make-foot-assets.py` (rerun it after changing a design). **124 game files** + 11 reference sheets. The game already runs with coloured placeholder figures; each real picture replaces its placeholder automatically.

## How

1. Paste the **style block** first (or put it in front of every prompt).
2. For each character paint its **sheet** first and keep it as the reference image.
3. Paint every pose of that character with the sheet attached; every pose prompt says "same character as the reference".
4. Characters: 1024x1024, flat plain white background, facing right, full body, no text. Cut the white out (`games-src/scripts/cutout.py`), convert to webp.
5. Save as the exact name in the table into `games/mainhattan-nightrun/media/foot/`, run `python3 games-src/nightrun/make-placeholders.py` (lists it in `media/ready.json`) and commit.

## Style block

> Painted cyberpunk Frankfurt 2099, hand-painted game art, rain, teal and magenta neon, readable silhouettes, crisp dark outline, chunky shapes that read at small size

Lists: `games-src/next-wave/flow-2d/mainhattan-nightrun/prompts-foot.json` (same prompts, `{"cards": {name: prompt}}`).
