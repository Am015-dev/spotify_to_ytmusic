## How to find X (named file, then the function)

1. **Change an enemy's HP**: base table: `en()` in b.js (line `const base={drone:{r:14,hp:2..}`); the 8 later kinds: `hp:` in zoo.js; scaling: grit.js (hp factor), scale.js/fair.js/hard.js (power-aware hull). Edit the owner, never a wrapper.
2. **Add a power-up**: timed music powers: `PWK` table in power.js (name, tip, bars, colour) + its effect in powerups.js (`PW2`) and levels/tips in powlevels.js (`PW3L`, `PW3NEW`); defensive/offensive/utility extras: arsenal.js (`PWX`). Add the id to the picker there, then a case in powers-test.js.
3. **Add a boss verb**: `vd('id','any'|boss,'what',(e,c,X,p)=>{..})` in bossmoves.js (see tri_burst, spokes); give it a telegraph with `bmMark`+`bmTelBul`, then list it in the boss's moveset `BMT` (top of bossmoves.js). Phases/HP: armour.js. Looks per phase: bossvis.js.
4. **Add a lesson**: `LSN` list (id, n, ph:[{id,say,chips,want,init}]) in lessons.js; helper foes `lsFoe`, `lsWave`; clear logic `lsClear`. Test: lessons-test.js (`?lessons=1` forces it in automation).
5. **Add an asset hook**: id in `assets-manifest.json` (nightrun/); picture only when listed in media/ready.json: `ART.img(id)` / `ART.anim(key)` in art.js, code shapes while missing in shapes.js; effects in fxwave.js; on-foot in footart.js. Policy: ASSET-POLICY.md.
6. **Change a price**: pit-stop shop: `SHOP.price(u)` + `UPG` in shop.js; permanent perks: `tpPrice` in upgrades.js; forge costs: forge.js; economy fit (hours to finish): econfit.js. 14 extra pit-stop upgrades: up2.js.
7. **Add a feature flag**: `if(RET.x===undefined)RET.x=!/[?&]x=0/.test(location.search);` in ret.js (or the layer's own first lines), new part file + one `rd('x.js')` in parts/build.py, header (below), a row appears here after `where.py`. Ship ON, measured; unfinished = default OFF.
8. **Change a formation / stage script**: formation library: formations.js (`vary`); per-stage scripts: stagescripts.js; remixed cut per run: remix.js; budget of bullets: density.js; pacing/length: pacing.js; director/songs: dir.js.
9. **Change an on-foot enemy or section**: enemy library footen.js, engine foot.js, the finished stage `zeil` footstage.js, art footart.js. Test: foot-test.js, footstage-test.js.
10. **Add a test**: copy the nearest `<name>-test.js` (react-test.js for a flag, bossmoves-test.js for bosses): Playwright, `?scn=`/flag URL, prints PASS/FAIL lines only; one at a time: `NODE_PATH=$(npm root -g) node games-src/nightrun/<name>-test.js`. Name it after the part (`x.js` -> `x-test.js`) so this table finds it; log in TEST-LEDGER.md.

## Do not read

- Built `games/mainhattan-nightrun/index.html`, `sw.js`, `x.js`, the joined `ui.js`: generated.
- `nightrun/MODULES.md` (36 KB, git-ignored): only for exact line numbers of one file; use `MODULES-COMPACT.md` first, or `games-src/scripts/find.sh <symbol> nightrun`.
- `analysis/`, `REVIEW-*.md`, `ASSETS-NEEDED*.md`, g.js / foot.js / ret.js / a.js / b.js whole: read a line range only.

Header standard for every new part: first lines `// PURPOSE: <one line>`, `// FLAG: <name (?name=0)|none>`, `// TEST: <x-test.js|none>` (guard.py errors on a new part without it, warns on old ones).
