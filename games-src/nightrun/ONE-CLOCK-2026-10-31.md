# One clock audit (WORKER-RULES 18c), 31 Oct 2026, W297

Method: `grep -rnE "Date\.now\(|performance\.now\(" parts/` = 85 hits in 40 files. Read-only; no game file was changed. Classes:
RENDER/UI (fine), INPUT TIMESTAMP (fine), AUDIO SYNC (wall time is the point: maps the audio clock to wall time), STORAGE/NETWORK (fine),
GAMEPLAY/RHYTHM (defect for the integration worker). Nothing in parts/waves, parts/enemies or parts/bosses reads wall time.

How the beat clock works: `core/a.js` `audible(ts)` returns `fbT` (game-time counter) when `SIM` is on, so judge/bpos are stepped in `simhunt`/`streetsim`.
Outside SIM, with audio running, it maps wall time to the AudioContext clock (`(p+CK.d)/1000`): by design.
