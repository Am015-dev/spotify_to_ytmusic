# parts/music

Build-order parts (`build.py` finds them by name, order is in `build.py`). Files:

- `flow.js`: the song never stops or stutters
- `musicpack.js`: polish music cues played by context
- `songs.js`: generated by analysis/song-energy.py: length in bars and lou

Hook layers registered here (`HOOK.name(prev=>...)` / `DRAW.extra`): none.
