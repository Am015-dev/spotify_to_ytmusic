# Nightrun: pictures for the new systems (W34)

Generated by `make-assets2.py` (re-run after changing a design). **115 files** in 5 groups. Each file already exists as a tiny text-free SHAPE placeholder in `games/mainhattan-nightrun/media/`; the game never shows it (placeholders are not in `media/ready.json`) and keeps drawing its own code shape until the real picture exists.

## How to hand in a picture

1. Paint it from `games-src/next-wave/flow-2d/mainhattan-nightrun/prompts-w34.json` (the style line is already in front of every prompt). Paint at 2x or larger.
2. Save it under the exact id (png/jpg/webp, `_` vs `-`, `copy` and `(1)` suffixes are forgiven) into **`assets-inbox/mainhattan-nightrun/`**.
3. Run `python3 games-src/scripts/ingest-assets.py` (sizes it, cuts the white / keys the black, writes `media/<id>.webp`, lists it in `ready.json`, moves the original to `done/`). Then `python3 games-src/nightrun/build.py` and commit.
4. `A` = wired: the picture appears in the game at once. `H` = a one-line hook is still needed at the spot named (the picture is loaded into `ART.bm` already, `ART.pic(id,w,x,y,rot,alpha)` returns false until then).

**Backgrounds.** `fx-w34-*` are light on PURE BLACK (the loader keys the black to transparent, like `fx-*`). Everything else: object on a flat plain WHITE background (the ingest cuts it out). No text, letters or numbers on any picture.
**Style line** (already in front of every prompt in `prompts-w34.json`): Neon cyberpunk game art, Frankfurt 2099, glowing teal/magenta/amber neon on dark steel, crisp bright outline, chunky simple shape that reads at 40 px, no text, no letters, no numbers.

**Priority** 1 = visible in every run, 2 = common, 3 = rare / polish.

**Totals:** 50 A (auto-wired) + 65 H (needs hook).
