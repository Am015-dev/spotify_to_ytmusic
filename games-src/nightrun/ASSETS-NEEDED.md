# Nightrun: art and sound still needed

Generated by `make-placeholders.py` from `assets-manifest.json`. Every file below already exists as a labelled **placeholder** (hatched box with its name and size) in `games/mainhattan-nightrun/media/`.
**To include real art:** save your image under the SAME file name and size into that folder and commit it. The game picks it up with no code change for the WIRED rows. RESERVED rows are art for features that are not built yet (or are drawn by code today); the placeholder is there so you can see the name and size, and the feature will use it when wired.

Style: the same painted look as the existing `spr-*`, `pk-*`, `fx-*`, `boss-*` files. WebP, transparent background for sprites and icons; **light on black** for `fx-*` (drawn additively). Sprites face LEFT (enemies, bosses) or RIGHT (player ships), as in `PAINTED-ART-HANDOFF.md`.

**53 files:** 25 WIRED (used now), 28 RESERVED (for planned features).
