Loop:
1. **Blind playtest first (before changing anything).** Start a static server (`python3 -m http.server 8811 --directory games &`) and use `games-src/scripts/drive-serve.js` (usage at the top; Chromium at /opt/pw-browsers/chromium; `npm i playwright-core` in a scratch folder outside the repo and set NODE_PATH to it — if the script needs `playwright`, symlink or alias it). Spawn 2 subagents in parallel as testers, each with its own driver port: (a) a casual player who skims and taps the big button, guided/first game if there is one; (b) an impatient player who skips any tutorial. Testers must NOT read any repo file — only what the game shows. Each keeps a per-screen log (what I think is happening | what I'd do | confidence 1–5 | confusion | fun 1–5) and ends with: goal and round in their own words, top 10 confusion moments with screenshot paths, "what just happened" moments, too much on screen, fun verdict.
2. **Fix the root causes**, in this order: real bugs (prove each with a failing test first); cause → effect for anything that changes the player's score/cards/pieces; one decision per screen with nothing hidden under fixed bars; the goal and score race always visible; plain words and tappable terms; trustworthy suggestions with a "why"; a guided first game that teaches one idea per step; pace (show computer moves as short narrated events, cut needless confirm screens); more visible stakes. Remove clutter rather than add panels. Don't change the game's rules unless they contradict rules-notes.md.
3. **Retest with 2 NEW blind testers** (fresh subagents, same rules). Acceptance: both can explain the goal and a round and say why they won/lost points; no unexplained score or card changes; no unreachable option; fun ≥ 3.5/5 average. If not met, fix and retest (max 3 rounds; then ship the best version with honest notes).
4. Keep existing tests green: the game's rules, hidden-info, net-strip, click, layout at 4 desktop sizes and 7 phone sizes (390x844, 390x763, 390x664, 375x553, 412x780, 844x390, 750x342) and its p2p test in `games-src/net/` if present. Run the full set once at the end.
