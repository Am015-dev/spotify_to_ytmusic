# Free art packs, part B (6 games, 2 picks each)

Checked 7 Nov 2026, 22:20 to 22:45 UTC. Every pick was downloaded through the proxy into its own dir under `/tmp/claude-0/s/work/<slug>/<pack>/`, unzipped, and the licence text read. Packs are NOT copied into the repo. Sheets are built from real extracted files (cells upscaled with nearest-neighbour only when tiny).

Coverage method: 6 slot types per game = card faces, tokens/pieces, board/map, portraits, backgrounds, icons/UI. Coverage % = slot types the pack fills in one consistent style / 6 (half-credit where the pack gives only part of a slot). Honest summary: no free pack covers everything; the best practical route is one hero pack per game plus a public-domain illustration set for portraits and backgrounds.

## Notes and gaps

- Extra desert option not ranked: Tiny Biomes Desert (aldrin572), https://aldrin572.itch.io/tiny-biomes-desert, LICENSE.txt "License: CC0. Free to use in personal and commercial projects." VERIFIED, but it is only one tileset, props and 3 background layers (~15% coverage).
- Rejected: Lornn "Fantasy Desert Backgrounds" (page says "Generated in Midjourney", AI); 40 Game Backgrounds #1 (CC0 but photographs); Damdan "Dive" (CC-BY-NC); Ravenmore Space Rage (paid).
- Met Open Access: the search endpoint answered but every `objects/<id>` lookup returned 404 from this machine, so no Met item could be verified. UNVERIFIED, none picked.
- Wikimedia Commons rate-limits this machine's IP (HTTP 429), so Dulac downloads were partial; licence metadata was read for all of them from the API.
- GitHub (game-icons repo tarball) is blocked here; icons were fetched one by one from game-icons.net instead.
- Style warning: the strongest-looking packs (Tiny Swords, Foozle) are pixel art. If the owner wants painted or vector, Haeckel and Dulac plates are the only free option found for card, portrait and background art, and no free pack was found that gives a complete painted token or board set for racing or space.
- Two licences carry a no-redistribution clause (Tiny Swords, Nautical Playing Cards): these allow use in a game but the games ship as public files, so get the owner's decision before wiring them.
